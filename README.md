# WSM — Windows Service Manager

WSM（Windows Service Manager）是一款基于 [WinSW](https://github.com/winsw/winsw) 的 Windows 服务管理工具。它帮助你将普通可执行程序注册为 Windows 服务，并在图形界面中完成安装、启停、配置、日志查看与卸载等日常运维操作。

---

## 系统要求

| 项目 | 说明 |
|------|------|
| 操作系统 | Windows 10 / 11（推荐 **Modern 版** `WSM.exe`） |
| 兼容版本 | Windows 7 / 8.1（**Legacy 版** `WSM-Legacy.exe`） |
| 权限 | **安装、卸载、启动、停止** 托管服务需要**管理员权限**；首次运行通常会弹出 UAC 提权 |
| 依赖 | 安装包已内置 WinSW，一般无需单独安装 |

---

## 安装与启动

### 通过安装包安装（推荐）

1. 从 [Releases](https://github.com/labyte/wsm/releases) 下载 `WSM-Setup-v*.exe`。
2. 以管理员身份运行安装程序，按向导完成安装。
3. 安装完成后可从开始菜单或桌面快捷方式启动 **WSM**。
4. 可选：安装时勾选「创建桌面快捷方式」。

### 从源码运行（开发者）

```powershell
dotnet restore WSM.sln
dotnet build WSM.sln -c Debug
dotnet run --project src/WSM.App.Modern/WSM.App.Modern.csproj
```

## 主界面导航

启动后，左侧为功能导航：

| 入口 | 用途 |
|------|------|
| **服务** | 查看已托管服务列表，启停、编辑配置、卸载 |
| **控制台** | 查看各服务的运行日志（out / err / 外部日志等） |
| **日志** | 查看 WSM 自身操作记录，或单服务的 WinSW wrapper 日志 |
| **添加** | 将新程序注册为 Windows 服务 |
| **设置** | 数据目录、WinSW 路径、操作日志、窗口行为等 |

界面底部会显示 Snackbar 提示（成功、警告、错误），无需弹窗确认即可完成大多数操作。

## 服务列表

「**服务**」页展示所有已通过 WSM 注册的 Windows 服务。

### 列表信息

- **服务名称**：在 WSM 与 Windows 服务管理器中显示的名称
- **状态**：运行中 / 已停止等
- **开始时间**：本次启动时间（未运行时为空）
- **程序目录**：被托管程序所在目录（可点击打开）

### 单个服务操作

每行提供快捷按钮：

- **启动** / **停止** / **重启**
- **更多（⋯）** 菜单：
  - **控制台**：跳转到「控制台」并聚焦该服务日志
  - **配置**：编辑服务参数（保存后通常会自动刷新 WinSW 配置）
  - **目录**：在资源管理器中打开程序目录
  - **卸载**：从 Windows 与 WSM 中移除该服务

### 批量操作

表头左侧复选框可全选；表头右侧工具栏支持：

- **一键启动所选**
- **一键停止所选**
- **一键卸载所选**（需二次确认）

右上角 **刷新** 可重新拉取服务状态。

## 添加服务

在「**添加**」页填写配置后，点击 **安装服务** 完成注册。安装过程会写入 WinSW 配置、注册 Windows 服务，并可选安装后立即启动。

### 配置页签说明

#### 基本

- **服务程序**：选择要托管的 `.exe`
- **可执行路径 / 工作目录 / 启动参数**：程序运行方式
- **服务 ID**：WinSW 内部标识（小写字母开头，仅含小写字母、数字、连字符）
- **显示名称 / 描述**：在系统中展示的信息
- **启动模式**：自动 / 手动 / 禁用；可勾选延迟自动启动
- **安装后启动**：安装完成后是否立即启动服务

#### 日志

两种日志方案二选一：

| 方案 | 说明 |
|------|------|
| **管理器提供（WinSW）** | 由 WinSW 写入 `stdout` / `stderr` 等到服务部署目录（默认在 `%ProgramData%\WSM\services\{服务ID}\`） |
| **外部日志** | 读取你指定的目录下日志文件（按扩展名过滤，自动选最新修改的文件） |

外部日志模式下可配置：

- 日志目录、扩展名（如 `.log;.txt`）
- 是否启用实时追踪、默认 tail 行数

#### 重启策略 / 依赖

- 配置服务失败后的重启策略、依赖的其他 Windows 服务等（按需填写）

安装过程中若需查看 WinSW 安装输出，会自动跳转到「**日志**」页。

> **提示**：安装、卸载、启动、停止服务前请确认 WSM 已以管理员身份运行（见「设置 → 运行权限」）。

## 服务控制台

「**控制台**」用于查看**被托管程序**的运行日志（非 WSM 操作日志）。

### 视图选择

| 下拉选项 | 显示内容 |
|----------|----------|
| **全部服务** | 合并显示所有已选服务的 out / err / 外部日志等 |
| **单个服务** | 仅显示该服务日志；状态栏会展示**当前日志方案**与**日志路径** |

### 工具栏

- **实时跟踪**：开启后约每 2 秒自动刷新，并滚动到最新行
- **自动换行**：长行是否换行显示
- **最大条数**：限制显示的最新日志行数（200～5000）
- **打开目录**：在资源管理器中打开当前服务日志所在目录
- **导出 / 复制 / 刷新**
- **清空**：清空当前视图范围内服务的 `.out.log`、`.err.log` 及已配置的外部日志文件内容（选择「全部服务」时会清理所有已安装服务；不可恢复，请谨慎）

---

## WSM 操作日志

「**日志**」页用于排查 WSM 与 WinSW 包装器自身的行为。

### 视图选择

| 下拉选项 | 显示内容 |
|----------|----------|
| **综合** | 读取 WSM 操作日志 `operations.log`（安装、卸载、启停、刷新等记录） |
| **单个服务** | 读取该服务目录下的 `*.wrapper.log`（WinSW 包装器日志） |

选择单个服务时，状态栏同样会显示日志方案与路径。

### 工具栏

与控制台类似，支持实时跟踪、自动换行、最大条数、导出、复制、刷新。

**清空** 行为因视图而异：

- **综合**：清空 `operations.log`
- **单个服务**：清空该服务的 wrapper 日志文件

## 设置

在「**设置**」页可调整全局选项（修改后多数项需点击对应 **应用** 按钮生效）。

### 运行权限

显示当前是否以管理员运行。若否，可点击 **以管理员身份重启**。  
托管服务的安装、卸载、启停均需要管理员权限。

### 窗口行为

关闭主窗口时：

- **最小化到系统托盘**（默认）：程序继续在后台运行
- **退出程序**：直接退出 WSM（仍可通过托盘菜单「退出」结束进程）

说明：最小化窗口仍会进入托盘；仅「关闭窗口」按钮受此项影响。

### 数据目录

WSM 存放服务配置、数据库、WinSW 部署文件的根目录，默认为：

```text
%ProgramData%\WSM
```

更改数据目录前会**自动停止全部托管服务**并迁移数据，建议操作后重启 WSM。

典型子目录：

```text
%ProgramData%\WSM\
├── data\wsm.db          # 服务配置数据库
├── logs\operations.log  # WSM 操作日志（默认）
├── services\{服务ID}\   # 各服务的 WinSW 部署与日志
└── winsw\               # WinSW 工具存储
```

### WinSW 执行配置

选择 WSM 调用哪个 WinSW 可执行文件（内置 x64 / x86 / .NET Framework、全局命令或自定义路径）。

### 操作日志文件

自定义 `operations.log` 保存位置；留空则使用默认 `数据目录\logs\operations.log`。

### 添加服务默认命名规则

配置在「添加」页选择程序后，自动生成 **服务 ID / 名称 / 描述** 的规则（如「程序名称」或「前缀 + 程序名称」）。

- **双击图标**：显示主窗口

  - **启动全部服务** / **停止全部服务**（按当前状态启用）
  - **退出**

## 卸载 WSM

### 从「设置 → 应用和功能」卸载

1. 建议先在 WSM **服务** 页卸载全部托管服务，或卸载时按提示选择 **是** 自动卸载全部托管服务。
2. 若跳过卸载服务，可能因文件被占用导致删除失败；可重新运行卸载程序并选择先卸载服务。
3. 卸载程序仅删除安装目录下的 WSM 程序；`%ProgramData%\WSM` 中的数据默认**不会**自动删除，可手动清理。

### 卸载单个托管服务

在 **服务** 页对目标服务选择 **卸载**（或批量卸载），将：

1. 停止服务（若正在运行）
2. 执行 WinSW `uninstall`
3. 从 WSM 数据库移除记录  

服务部署目录中的文件可能仍保留，必要时可手动删除 `services\{服务ID}` 文件夹。

## 常见问题

**Q：提示需要管理员权限怎么办？**  
A：在「设置」中点击「以管理员身份重启」，或右键 `WSM.exe` → 以管理员身份运行。

**Q：服务安装成功但启动失败？**  
A：在「日志」页选择该服务查看 wrapper 日志；在「控制台」查看程序 out/err 日志；确认可执行路径、工作目录与参数是否正确。

**Q：控制台与「日志」页有什么区别？**  
A：**控制台**看的是**被托管程序**的输出；**日志 → 综合**看的是 **WSM 自己的操作记录**；**日志 → 单服务**看的是 **WinSW 包装器**日志。

**Q：更改数据目录后服务找不到了？**  
A：数据目录迁移会重绑服务路径，完成后请在服务列表点击刷新；若异常可在设置中确认目录并重启 WSM。

**Q：如何备份？**  
A：备份整个 WSM 数据目录（默认 `%ProgramData%\WSM`）即可，其中包含数据库与各服务配置。
