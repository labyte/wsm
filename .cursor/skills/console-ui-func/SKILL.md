# 控制台页面功能

## 适用场景
- 修改 `ServiceConsoleView`的布局、功能按钮。
- 修改 `ConsoleLogView`的滚动条、功能按钮、日志显示格式。
- 混合显示所有服务日志，单独显示指定服务日志。
- 启动加载历史日志、日志实时更新。

## 技术约束
- 使用 `MaterialDesignThemes.Wpf` 的现有组件与样式键。
- 日志功能基于 assets\winsw\logging-and-error-reporting.md 文档。


## 实施规则
1. ServiceConsoleView 布局，从左到右依次
   - 服务列表标题。
   - 下拉框选择单个服务或全部。
   - checkbox 启用实时跟踪。
   - checkbox 自动换行。
   - 下来框选择显示的最大日志条数。
   - toolbar 组件负责 导出、复制、刷新、清空。
   


2. 控制台UI
   - 仅显示垂直滚动条，去除底部横向滚动条。
   - 垂直滚动条常态下不显示两端的箭头，滚动条开端改细，鼠标移入时恢复原始样式，但是注意滚动条的颜色和控制台本身的黑色要对比度高。

3. 控制台显示的日志对应功能按钮的功能
   - 进入时加载历史日志
   - 支持全部日志混合显示和单个服务日志显示
   - 支持实时跟踪切换。
   - 支持自动换行切换。
   - 根据设置的最大条数实时删除旧日志。
   - 支持清空日志，同时删除文件内容。


## 变更后校验
- 必须执行：
  - `dotnet build WSM.sln`
- 若涉及 XAML 样式绑定：
  - 确认导航标题、图标、选中态、主题切换均可见且可交互。
