# 控制台页面功能

## 适用场景
- 修改 `LogViewerView`的布局、功能按钮。
- 混合显示所有服务日志，单独显示指定服务日志。
- 启动加载历史日志、日志实时更新。

## 技术约束
- 使用 `MaterialDesignThemes.Wpf` 的现有组件与样式键。
- 注意此功能不同于控制台日志，此功能时WSM本身操作的日志
- 日志文件来源于 *.wrapper.log
- 清空日志仅清空 *.wrapper.log

## 实施规则
1. 布局，从左到右依次
   - 服务列表标题(WSM操作日志)。   
   - 服务选择下拉框，包含全部
   - checkbox 启用实时跟踪。
   - checkbox 自动换行。
   - 下来框选择显示的最大日志条数。
   - toolbar 组件负责 导出、复制、刷新、清空。
   


2. 控制台UI
   - 使用封装好的

3. 控制台显示的日志对应功能按钮的功能
   - 进入时加载历史日志 
   - 选择全部服务时，根据时间排序
   - 支持实时跟踪切换。
   - 支持自动换行切换。
   - 根据设置的最大条数实时删除旧日志。
   - 支持清空日志，同时删除文件内容。


## 变更后校验
- 必须执行：
  - `dotnet build WSM.sln`
- 若涉及 XAML 样式绑定：
  - 确认导航标题、图标、选中态、主题切换均可见且可交互。
